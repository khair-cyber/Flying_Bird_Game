# Flying Bird Game

Game sederhana berbasis **HTML + JavaScript** dengan kontrol kamera.  
Pemain menggerakkan burung menggunakan tangan/jari yang terdeteksi kamera, mirip konsep *Flappy Bird*.

## Cara Main
1. Buka link game: [Flying Bird Game](https://khair-cyber.github.io/Flying_Bird_Game/)
2. Klik **Allow Camera** saat browser meminta izin.
3. Gunakan tangan/jari di sisi **kanan layar** untuk mengontrol burung.
4. Hindari tabrakan dengan pipa, kumpulkan skor sebanyak mungkin.
5. Jika kalah, klik **Coba Lagi** untuk restart.

## Fitur
- Background kamera real-time.
- Kontrol burung dengan deteksi tangan.
- Efek suara: flap, skor, dan game over.
- Tampilan skor langsung di layar.
- UI sederhana dengan layar start dan game over.
